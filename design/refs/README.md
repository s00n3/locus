## Важно про ширины

- **Десктопные макеты нарисованы на 1440**, а не на 1840/1920. Контейнер
  `max-width: 1840px` из handoff — это верхняя граница; пропорции и отступы
  снимаются с 1440-го фрейма.
- **Мобильные макеты нарисованы на 400**, а не на 375. Брейкпоинт в коде — 375
  (ТЗ, раздел 2), макет на 400 берётся как референс пропорций.

## Как перевыгрузить

Через Figma MCP (вариант A, ТЗ 10.3) — `get_screenshot` с `fileKey` + `nodeId`.

Через REST API (вариант B, ТЗ 10.4), нужен `FIGMA_TOKEN`:

```bash
curl -H "X-Figma-Token: $FIGMA_TOKEN" "https://api.figma.com/v1/images/GZMSQRuw0nDX9b4Bxk9MSc?ids=9:23,9:1473,9:638,9:2529,9:3097,9:3507&scale=2&format=png"
```
