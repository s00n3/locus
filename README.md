# ЛОКУС

Сайт цифровой проектной школы **ЛОКУС** — Цифровая кафедра Сеченовского университета.
Лендинг + страницы «Проекты» и «Сообщество» + попапы (формы, детали треков).
Тема только тёмная. Верстка по макету Figma **DC-Final**.

## Стек

- [Astro 5](https://astro.build) — статическая генерация, ноль JS по умолчанию
- React 19 — только островами, там где есть интерактив
- Чистый CSS + CSS-переменные (дизайн-токены из Figma), без UI-фреймворков
- IBM Plex Sans / Mono — self-host, OFL

## Запуск

```bash
npm install
```

```bash
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на `localhost:4321` |
| `npm run build` | Прод-сборка в `./dist/` |
| `npm run preview` | Локальный просмотр собранного |

## Порядок работы

Верстка идёт **строго поблочно**: сначала весь десктоп блок за блоком, потом так же
поблочно адаптив. Каждый блок сверяется с Figma и уходит отдельным коммитом.
Подробности и правила — в [AGENTS.md](AGENTS.md).

## Редактирование контента

Списки (треки, кейсы, проекты, персоны, FAQ) лежат YAML-файлами в `src/content/`
и правятся через git-админку **[Pages CMS](https://pagescms.org)** — конфиг
в [.pages.yml](.pages.yml). Сохранение в админке создаёт коммит, коммит запускает
пересборку. Ни базы, ни сервера, ни абонентской платы.

Редакторов можно приглашать по email — аккаунт на GitHub им не нужен.

Заявки с формы сюда не попадают: персональные данные по 152-ФЗ хранятся только
в России, а репозиторий на GitHub. Бэкенд форм подключается отдельно, на сервере
университета.

## Деплой

Пуш в `main` → GitHub Actions собирает и выкладывает на GitHub Pages:
**https://s00n3.github.io/locus/**

Сайт лежит в подпапке, поэтому в `astro.config.mjs` задан `base: '/locus'`.
Внутренние ссылки и ассеты строятся с учётом этого — см. [AGENTS.md](AGENTS.md).
Когда появится свой домен, `base` убирается, `site` меняется на домен.

## Что ещё не решено

- Домен (сайт вне зоны `sechenov.ru`) — нужен для `site` в `astro.config.mjs`, canonical и OG
- Куда уходят заявки: почта / CRM / serverless-обработчик
- Политика конфиденциальности под внешний домен, оператор ПД (152-ФЗ)
- 8 изображений под плейсхолдеры «ЗАМЕНИТЬ НА PNG» и иконки 8 направлений
- Favicon, OG-изображение, тексты title/description
